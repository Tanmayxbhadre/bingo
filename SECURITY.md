# Security Policy

## Supported Versions

We release security updates and bug fixes for the current active release line.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The Bingo.io team takes security and player safety seriously. If you discover a security vulnerability or exploit in the game logic, server endpoints, or WebSocket handlers, please report it responsibly:

1. **Do not create public GitHub issues** for suspected security vulnerabilities.
2. Email details of the issue to **tanmaybhadre6@gmail.com** with the subject line:
   `[SECURITY] Bingo.io Vulnerability Report`.
3. Please include:
   - A clear description of the vulnerability.
   - Steps or code to reproduce the issue (proof of concept).
   - Potential impact on rooms, players, or server stability.
   - Any suggested remediations if known.

## Response SLA

- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Patch Deployment:** Target resolution within 14 days, depending on severity.

Thank you for helping keep Bingo.io safe and fair for everyone!
