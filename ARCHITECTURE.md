## 🔒 Authoritative Server Model & Anti-Cheat

Bingo.io follows a **server-authoritative model**:

1. **Card Generation**:
   - Each player's 5×5 card is generated by the server via Fisher-Yates shuffle of integers $1 \dots 25$.
   - Cards are stored in memory on the server (`Room.players`).
2. **Turn Validation**:
   - Players can only call numbers during their active turn (`turnPlayerSessionToken === sessionToken`).
   - The server verifies that the called number has not been previously called and is within $1 \dots 25$.
3. **Optimistic Client Updates**:
   - The client applies immediate visual stamps (0ms latency feedback).
   - The server verifies markings and authoritative line completions.
4. **Authoritative Win Detection**:
   - The server runs `BingoEngine.evaluateLines(card)` after every call or mark.
   - Victory is only declared when the server confirms $\ge 5$ completed lines.

## 📐 Board Representation & Line Geometry

The 5×5 grid contains 25 cells indexed $0 \dots 24$:

$$\text{row} = \lfloor \text{index} / 5 \rfloor, \quad \text{col} = \text{index} \pmod 5$$

There are **12 winning lines**:
- **5 Rows**: `[0..4]`, `[5..9]`, `[10..14]`, `[15..19]`, `[20..24]`
- **5 Columns**: `[0,5,10,15,20]`, `[1,6,11,16,21]`, `[2,7,12,17,22]`, `[3,8,13,18,23]`, `[4,9,14,19,24]`
- **2 Diagonals**:
  - Main diagonal: `[0, 6, 12, 18, 24]`
  - Anti-diagonal: `[4, 8, 12, 16, 20]`

## 🤖 AI Bot Heuristic Loop

The AI bot evaluates urgency across all 12 line definitions:
- Lines with **4 marked cells**: weight $+250$ (immediate winning move).
- Lines with **3 marked cells**: weight $+90$.
- Lines with **2 marked cells**: weight $+35$.
- Lines with **1 marked cell**: weight $+15$.

Numbers with maximum aggregated weights are prioritized with human-like delays:
- **Calling delay**: $1.2\text{s} - 2.2\text{s}$.
- **Reaction marking delay**: $400\text{ms} - 1000\text{ms}$.
